### Установка (Beta)
1. Установите загрузчик [Millennium](https://steambrew.app/) (версии **3.6.3** или новее) для клиента Steam.
2. Скачайте файл `com.0wn3df1x.bibliotekarsha.star` из раздела [Releases](https://github.com/0wn3dg0d/Bibliotekarsha/releases).
3. Перейдите в папку плагинов Millennium (например, `C:\Program Files (x86)\Steam\millennium\plugins`) и перенесите туда скачанный файл.
4. В клиенте Steam откройте **Steam → Настройки → Millennium → Плагины**, активируйте **Bibliotekarsha (Beta)** и сохраните изменения.
5. Для управления модулями, встроенной справкой со скриншотами и единым бэкапом используйте кнопку **⚙ BSH** в верхней панели клиента Steam.
